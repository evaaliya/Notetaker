## Сейчас

`NoteEditorPage` — ручной `submit`: `createNote` / `patchNote` по кнопке «Сохранить».  
`AttachmentsPanel` при `noteId === null` только пишет «Сохраните заметку…».

## Минимальный план (только web + DECISIONS)

**Идея:** как сейчас — запись на сервере появляется только при содержимом; дальше debounce-patch. Очередь файлов — только в памяти до первого `id`.

### 1. `NoteEditorForm` — autosave
- Триггер **создания** (без debounce или ~100 мс): первый непустой `title`/`body` **или** файл в очереди. Пустой `/notes/new` → **нет** `POST`.
- После появления `id`: `navigate(..., { replace: true })` как сейчас; дальше **debounce 600 мс** → `PATCH` с `version`.
- Один in-flight create (ref/mutex), чтобы двойной ввод не дал две заметки.
- Кнопку «Сохранить» заменить индикатором: «Сохранение…» / «Сохранено» / ошибка; «Отмена» — сброс черновика и уход (без пустой записи).
- Перед уходом с грязным черновиком (`beforeunload` + при смене маршрута): **flush** — дождаться create/patch и upload очереди.

### 2. `AttachmentsPanel` — очередь
Проброс с формы:
- `pendingFiles` + `onPendingChange`
- без `noteId`: файлы в очередь (превью через `URL.createObjectURL`), не на сервер; добавление в очередь → колбэк «создай заметку»
- после `noteId`: `upload` всех pending по очереди, затем обычный upload

### 3. Защита (п.8) — без смены бэкенда
| Риск | Мера |
|---|---|
| Быстрый уход с `/notes/new` | flush перед navigate; блокер маршрута пока идёт create/upload |
| Двойной create | mutex на create |
| Reload до create | `sessionStorage` черновика (title/body/starts/tags/offsets) на ключ `notetaker.draft.new`; **File в sessionStorage не кладём** |
| Reload с только-файлом до create | создать заметку **сразу** при выборе файла (без текстового debounce), затем upload — окно потери минимально |
| Reload после create | данные уже на сервере |

IndexedDB для файлов — **не** в минимальный объём (можно позже).

### 4. Что не меняем
- Схема, API, воркер, `NoteSidePanel`, QuickAdd  
- Оптимистичный `version` / 409 — как сейчас при concurrent patch
