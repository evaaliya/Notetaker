**User**

1. Звук: мягкая мелодия около 3 секунд (например, восходящий перелив из
   трёх нот с плавным затуханием, Web Audio API на лету, файлов нет),
   повтор каждые ~4 секунды, пока не остановят. Не резкий, не как
   сообщение в чате.
2. Остановка: кнопка «Выключить звук» в уведомлении (toast) и в панели
   уведомлений; также автоматически, когда уведомление помечено
   прочитанным («Прочитано», «Готово»). Пока звук играет, рядом с
   колокольчиком виден индикатор «Звучит сигнал».
3. Несколько вкладок: звучит только одна вкладка (выбор через
   BroadcastChannel или localStorage), остальные молчат. Остановка в
   одной вкладке останавливает звук во всех.
4. Настройки: переключатель «Звук уведомления» остаётся; добавь
   «Повторять, пока не выключу» (по умолчанию включён). Выключен: один
   сигнал, но такой же мелодичный. Хранение в localStorage, как у
   остальных настроек.
5. AudioContext запускается по первому касанию страницы; если звук
   заблокирован, покажи в уведомлении подсказку «Нажмите на страницу,
   чтобы включить звук» вместо молчаливого пропуска.
6. Тесты: юнит alarmLoop_starts_repeats_and_stops (поддельные
   AudioContext и таймеры, без реального звука) и e2e
   e2e_alarm_stops_on_dismiss (уведомление через E2E_HOOKS, видна кнопка
   «Выключить звук», после нажатия индикатор исчезает).
