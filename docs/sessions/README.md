# Сессии агента

Сюда кладутся экспорты чатов Cursor и журнал промптов.

## Как сохранять
1. В Cursor откройте чат → меню чата → экспорт в Markdown (если пункта нет в вашей версии — скопируйте переписку вручную).
2. Имя файла: `YYYY-MM-DD_HHMM_M<этап>_<тема>.md`, например `2026-10-23_1430_M0_skeleton.md`.
3. Один чат — один этап: так сохраняются и временные метки хода работы.

## Когда
После каждого этапа, до закрытия чата. Потерянный чат не восстановить.

## Файлы
- `PROMPTS.md` — краткий журнал ключевых промптов.
- `*.md` — экспорты сессий.
