# Прототип интерфейса

Файлы `*.dc.html` — разметка и стили одобренного прототипа (по одному файлу на экран):
`Upcoming` (Ближайшее), `Main` (Календарь), `List` (Список), `Tags` (Метки), `Trash` (Корзина),
`Settings` (Настройки), `Mobile` (телефон).

Это справочный материал: открывать как текст и брать из него цвета, отступы, структуру.
Не копировать как есть. Реализация идёт в React по описанию в `docs/FRONTEND.md`.
Тег `<x-dc>` и скрипт `support.js` относятся к инструменту прототипирования и в проект не переносятся.
