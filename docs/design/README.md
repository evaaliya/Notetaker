# Прототип интерфейса

Файлы `*.dc.html` — разметка и стили одобренного прототипа, по одному файлу на экран:
`Upcoming` (Ближайшее, с панелью уведомлений), `Main` (Календарь), `List` (Список), `Tags` (Теги),
`Trash` (Корзина), `Settings` (Настройки), `Mobile` (телефон).

Справочный материал: открывать как текст и брать цвета, отступы, структуру. Не копировать как есть.
Реализация идёт в React по описанию в `docs/FRONTEND.md`. Тег `<x-dc>` и `support.js` относятся к инструменту
прототипирования и в проект не переносятся.
