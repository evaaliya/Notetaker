# Чем делали

- **Инструмент:** Cursor (агентный режим).
- **Модель:** Auto (выбирает между моделями, Grok 4.7, Grok 4.6, Claude Opus 5.5, Claude Opus 5.5, Claude Opus 4.8, Gemini 4 Aragon, Muse Wonder, Claude Fable 5.1, Claude Sonnet 5.5, Claude Sonnet 5, Codex 5.3, Claude Opus 4.7, Kimi K2.7 Code, deepseek-chat, deepseek-reasoner,).
- **Почему так:**  Cursor видит весь репозиторий и правит файлы напрямую, что удобно для проекта из нескольких сервисов; модель выбрана за качество работы с кодом и длинным контекстом спеки, за интерфейс, и за богатый арсенал инструментов. Еще за бюджетность подписки за первый месяц 17 USD, и доступность тех же дорогих моделей от Антропик.

## Как организован процесс

- Требования зафиксированы в `spec.md` до начала кода.
- Правила агента — в `.cursor/rules/` (подгружаются в каждую сессию).
- Работа разбита на этапы M0–M6; каждый этап — отдельные коммиты, запись в `docs/DECISIONS.md` и обновление `STATUS.md`.
- Экспорт чатов Cursor — в `docs/sessions/`.
