# Интерфейс Notetaker: дизайн и правила реализации (этап M7)

Источник правды по виду. Логику, API и тесты этапов M0–M6 этот документ не меняет.
Одобренный прототип лежит в `docs/design/` (разметка и стили по экранам).

## 1. Принципы
- Напоминание считывается картинкой, а не чтением текста: у каждой заметки есть иллюстрация.
- Метка видна везде, где видна заметка (календарь, список, «Ближайшее», корзина, панель заметки, телефон).
- Стиль: тёплая бумага, заголовки с засечками, один акцентный цвет. Без стекла, без градиентов-«неона», без помпонов.
- Папок в продукте нет (в требованиях только метки). Метка играет роль папки: клик по метке в левой панели открывает «Список» с этим фильтром.
- Язык интерфейса русский, имена в коде английские.

(`@fontsource/inter`, `@fontsource-variable/source-serif-4`), не через CDN: проект должен работать без сети.
Размеры: h1 36px, h2 38px только в блоке «Следующее напоминание», подписи-метки 11px капсом с межбуквенным 0.1em.

## 3. Метки
- В БД у метки остаётся `color` `#RRGGBB` (спека §3). Новые поля не добавлять.
- Из базового цвета считаются две производные (функция `tagColors(hex)` в `web/src/lib/tagColors.ts`):
  - заливка: смешение базового цвета с белым 88%;
  - цвет текста и полоски: базовый цвет, затемняемый шагами, пока контраст с заливкой не станет не ниже 4.5:1.
- Компонент `TagPill`: высота 24px, радиус 12, слева точка 6px цвета текста, заливка из функции выше.
- Палитра выбора цвета в редакторе метки: `#3E6FB0 #6B4A9E #B07A1C #2F6B4B #B4402F #2E7F8F #8A4B6E #5B5348`,
  выбранный отмечен контуром 2px. Любой другой `#RRGGBB`, уже сохранённый ранее, остаётся валидным.
- Заметка без метки: нейтральные серо-бежевые цвета, без пилюли.
- Несколько меток: цвет карточки и полоски по первой метке, пилюли показываются все (в календаре не больше двух и «+N»).

## 4. Иллюстрации к заметкам
- Компонент `NoteIllustration` (квадрат со скруглением 12, заливка и линия цвета первой метки).
- Набор линейных иконок локальный (пакет `lucide-react` или свои SVG), без сети. Размеры: 34px в календаре,
  44px в списке, 64px на телефоне, 120px в блоке «Следующее напоминание».
- Выбор иконки: чистая функция `pickIllustration(title, body, tagName)`:
  1. ключевые слова в названии и тексте (русские и английские), например: созвон/звонок/call → телефон;
     тренировка/спорт/зал → гантель; аренда/квартира/дом → дом; подарок/день рождения → подарок;
     лекция/учёба/экзамен/книга → книга; врач/лекарство → медицинский крест; оплата/счёт → кошелёк;
  2. иначе по названию первой метки;
  3. иначе нейтральная иконка «заметка».
- Правила составляются таблицей в одном файле, без вызовов моделей. Юнит-тесты на таблицу ключевых слов обязательны.
- Генерация картинок моделью в M7 не входит (нужен ключ и сеть, а проект должен запускаться локально без них).

## 5. Каркас
- Слева вертикальная панель 248px, фон `--sidebar`: логотип-слово «Notetaker» с засечками; пункты
  Ближайшее, Календарь, Список, Корзина (со счётчиком), Настройки; ниже блок «Метки»: пилюля и счётчик, клик
  ведёт в «Список» с фильтром; «Управлять метками» ведёт на экран меток; внизу «Уведомления» с колокольчиком и счётчиком непрочитанных.
- Активный пункт: фон `--surface`, рамка `--line`.
- Сверху в основной области: h1 с подписью, поиск 220px, акцентная кнопка «Новая заметка».
- Экран «Метки» (CRUD, цвет): строки с цветным квадратом 36px, пилюлей, числом заметок, кнопками «Переименовать» и «Удалить»;
  справа карточка «Новая метка» с палитрой.

## 6. Экраны
**Ближайшее.** Герой «Следующее напоминание»: название serif 38px, пилюля метки, время, обратный отсчёт
«через N минут» акцентным цветом 54px (на основе `useNow`), кнопки «Готово» и «Отложить на 10 минут»
(отложить = сдвиг времени заметки через существующий PATCH с `version`). Ниже «Позже сегодня», «На этой неделе»
(карточки с большой иллюстрацией), «Прошедшие» (приглушены, подпись «просрочено»). Живой переход в «Прошедшие» уже есть, сохранить.

**Календарь.** Неделя, месяц, день. Событие: заливка цвета метки, полоска 4px слева, иллюстрация 34px, название, время, пилюля метки.
Сегодняшняя дата в акцентном круге. Месячный вид показывает метку так же (цветная заливка и полоска, пилюля при наличии места).

**Список.** Строка: иллюстрация 44px, название и первая строка текста, пилюли меток, дата и время, подпись интервала напоминания,
переключатель активности. Над списком панель фильтров: метки-пилюли, статус, сортировка. Виртуальная прокрутка и серверный поиск остаются.

**Корзина.** Строка с иллюстрацией, пилюлей, под названием «исчезнет через N дн.» с полоской прогресса из 30 дней,
кнопки «Восстановить» и «Удалить навсегда». Пояснение про 30 дней внизу.

**Настройки.** Почта; часовой пояс с поиском по списку (уже есть); переключатель «Звук уведомления»;
переключатель «Анимация колокольчика». Эти два значения хранятся в `localStorage` на устройстве (в БД новых полей нет).

## 7. Календарь: исправление и перетаскивание в корзину
1. В недельном виде нельзя положить в одну ячейку больше трёх заметок. Требований такого ограничения нет.
   Найди причину (настройки FullCalendar вроде `eventOverlap`, `slotEventOverlap`, `eventMaxStack`, `dayMaxEvents`
   или собственный код), исправь так, чтобы любое число заметок помещалось и читалось (события в слоте располагаются рядом
   или стопкой без наложения), запиши причину в `docs/DECISIONS.md`.
2. Корзина при перетаскивании: когда пользователь тянет событие, внизу области календаря появляется зона
   «Отпустите, чтобы убрать в корзину · вернуть можно в течение 30 дней» (пунктир, `--danger-soft`). Отпускание над зоной
   вызывает то же удаление, что кнопка в панели заметки. Для вхождения серии сначала показывается уже существующий диалог
   области (только это / это и следующие / все). После удаления появляется toast с кнопкой «Отменить» (восстановление из корзины).
   Если пользователь отпустил вне зоны, действует обычный перенос на новую дату.
3. Клавиатурная альтернатива: кнопка «Удалить» в панели заметки остаётся.

## 8. Уведомления
- При приходе уведомления (WebSocket) колокольчик качается один раз (анимация 0.8 с), toast остаётся как есть.
- Звук: короткий двухтональный сигнал, генерируется Web Audio API на лету (файлов нет). Автовоспроизведение браузеры блокируют
  до первого касания страницы: «разбудить» `AudioContext` по первому клику, не показывать ошибку, если звук заблокирован.
- Всё отключается настройками и `prefers-reduced-motion` (анимации).

## 9. Телефон (ширина до 640px)
- Левая панель уходит в нижнюю панель вкладок (Ближайшее, Календарь, Список, Корзина, Ещё).
- «Ближайшее»: приветствие, карточка следующего напоминания (иллюстрация 64px качается в момент уведомления),
  ниже список остальных.
- Кнопка «Новая заметка» открывает нижний лист: название, время, чипы «за 10 мин / за час / за день», метки-пилюли, кнопка «Добавить».
- Цели нажатия не меньше 44px. Web Push не входит: на телефоне уведомления приходят, пока страница открыта.

## 10. Доступность
- Контраст текста не ниже 4.5:1 (проверка тестом для `tagColors`).
- Видимый фокус `outline 2px --accent`, у иконок-кнопок `aria-label`, переключатели с `role="switch"` и `aria-checked`.
- Не передавать смысл только цветом: у метки всегда есть название.
- `prefers-reduced-motion`: отключить тряску и качание.

## 11. Тесты и критерий готово
- Все 46 тестов `make test` и 14 e2e продолжают проходить. Если меняется разметка, поправить селекторы
  (сохранить существующие `data-testid`, где возможно).
- Новые юнит-тесты: `tagColors_contrast_ge_45`, `tagColors_tint_is_light`, `pickIllustration_keywords_ru_en`,
  `pickIllustration_falls_back_to_tag_then_default`.
- Новые e2e: `e2e_tags_visible_everywhere` (пилюля метки есть в календаре, списке, «Ближайшем», корзине),
  `e2e_week_many_notes_in_slot` (пять заметок в один слот), `e2e_drag_to_trash` (перетащить, заметка в корзине, «Отменить» возвращает),
  `e2e_mobile_quick_add` (viewport 390×844: создать заметку через нижний лист).
- Скриншоты каждого экрана в `docs/design/screens/` (Playwright, ширина 1280 и 390), чтобы можно было сравнить с прототипом.

## 12. Вне объёма
